# 🖼️ Live Photo Editor

A real-time photo editing application built using **Python, OpenCV and NumPy**.

The project allows users to load an image and edit it instantly using sliders and keyboard shortcuts.

## ✨ Features

- ☀️ Brightness adjustment
- 🌓 Contrast adjustment
- 🌈 Saturation adjustment
- 🌫️ Blur effect
- ✨ Image sharpening
- ↔️ Horizontal flip
- ↕️ Vertical flip
- 🔄 Rotate image by 90°
- ⚫ Grayscale conversion
- 🔙 Undo / Redo
- ♻️ Reset to original image
- 💾 Save edited image
- 📁 Choose images from PC
- 🎚️ Real-time slider controls
- ⌨️ Keyboard shortcuts

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Tkinter

## 📋 Keyboard Shortcuts

| Key | Function |
|-----|----------|
| H | Flip Horizontal |
| V | Flip Vertical |
| R | Rotate 90° |
| G | Grayscale |
| O | Reset Original |
| U | Undo / Redo |
| S | Save Image |
| Q | Quit |
